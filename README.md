# 🚗 부릉부릉 토이카 런 (Toy Car Run)

- 저장소: https://github.com/kjt7942/toy-car-run
- 한줄 설명: 말랑한 장난감 감성의 세로 화면 자동차 장애물 회피 게임. 브라우저 하나로 PC·모바일 모두 즐길 수 있습니다.

---

## 1. 목적

- 설치 없이 링크 하나로 바로 켜서 1~3분 즐기는 캐주얼 아케이드 게임 만들기
- "운이 나빠서 죽었다"가 아니라 **"내가 잘못 읽어서 죽었다"** 고 느끼게 하는 설계 — 무작위 스폰 대신 사람이 짠 패턴, 위험을 감수하면 보상이 커지는 구조
- 한 판이 끝나도 다음 판을 켤 이유가 남도록 — 기록, 차고, 도전과제, 오늘의 도전
- 외부 이미지·사운드 파일 없이 **Canvas2D + Web Audio만으로** 그래픽과 사운드를 전부 코드로 합성

## 3. 주요 기능

### 기본 조작
- 차는 화면 아래에 고정, 도로가 위에서 아래로 흐르고 **좌우로만** 움직임
- PC: `◀ ▶` 또는 `A / D`, 모바일: 화면 아래 왼쪽/오른쪽 터치 (투명 터치 영역, 판 시작 때 3.2초 조작 가이드)
- `Space`로 일시정지(HUD의 ⏸ 버튼도 있음), 게임오버 뒤 `Space`/`Enter`로 바로 재시작
- 출발 전 카운트다운 1.8초

### 점수 · 콤보
- 주행 거리(초당 60점) × 레벨 보너스 × 콤보 배수
- 코인(70점), 장애물 틈에 박힌 **위험 코인**(150점, 경고 링 표시), **아슬아슬 스치기**(16px 이내, 60점)
- 코인·스치기 3회마다 콤보 배수가 1단계씩 올라 최대 x8. 4초 동안 획득이 없거나 피격되면 콤보가 끊김
- 도로 가운데에서 4초 넘게 버티면 견제가 들어옴(가운데만 지키는 안전 플레이 방지)

### 장애물 (패턴 스폰)
- 장애물 종류: 고깔 콘, 바위, 바리케이드, 오일 드럼통, 바나나 껍질, 방해 차량
- 사람이 짠 11개 패턴을 레벨별 가중치로 뽑아 배치: `single`, `coinTrail`, `zigzag`, `wallGap`, `puddleField`, `funnel`, `traffic`, `gauntlet`, `gate`, `crossing`, `powerup`
- 레벨은 점수가 아니라 **주행 거리** 기준(6,500px부터 레벨마다 1.12배씩 늘어남). 속도는 3.6에서 시작해 약 80초 뒤 최고 9.0
- **바나나 껍질**: 목숨은 안 깎지만 2.5초간 접지력을 잃고 차가 빙글빙글 돎
- **오일 드럼통**: 부딪히면 카메라 렌즈에 기름 방울이 튀어 화면 위쪽을 잠깐 가림

### 아이템 6종
| 아이템 | 효과 |
|---|---|
| 🪙 코인 | 점수 + 차고용 코인 |
| ⚡ 부스터 | 4초 동안 질주, 장애물을 부수고 지나감(파괴 120점) |
| 🛡️ 보호막 | 피격 1회 방어 |
| 🧲 자석 | 6초 동안 코인을 끌어당김 |
| ❤️ 하트 | 목숨 1 회복, 목숨이 가득 차 있으면 400점 |
| 🐢 슬로우 | 5초 동안 세상이 55% 속도로 느려짐 |

### 선택 게이트
- 도로가 **황금 문**(코인 2배, 대신 문 뒤에 장애물이 몰려 있음)과 **초록 문**(안전)으로 갈라짐

### 추격전
- 길을 건너는 사람·동물을 치면 목숨 대신 **경찰차가 쫓아옴**
- 15초 버티면 탈출 보상(코인 25 + 1,200점). 경찰차를 장애물로 유인해 박게 하면 약 1.2초 주춤함

### 라스트 스탠드
- 목숨이 1개 남으면 잠깐 시간이 느려지고 화면 가장자리가 빨갛게 맥동

### 월드 구간 (바이옴)
- 레벨이 오를 때마다 풍경이 약 2.5초에 걸쳐 바뀌고 구간 이름 배너가 뜸
- 🌼 봄 들판 → 🍇 샤인머스켓 포도밭 → 🍁 단풍길 → 🏖️ 바닷가 도로 → 🌙 반짝 밤거리 → ⛄ 눈꽃 설원
- 구간마다 BGM 조성이 바뀜
- 이전 최고 거리 지점에 체크무늬 결승선을 깔아 "여기만 넘으면 신기록"을 보여줌

### 메타 진행 (localStorage 세이브)
- TOP 5 기록판, 누적 주행 거리, 누적 코인, 최고 콤보
- **도전과제 12종** (첫 주행, 콤보 x4/x8, 코인 50개, 스치기 20번, LV.5/10, 무결점, 파괴왕, 150,000점/500,000점, 3,000m)
- **차고 6대** — 색만 다른 게 아니라 차마다 특성이 하나씩 있음

| 차 | 가격 | 특성 |
|---|---|---|
| 클래식 | 0 | 무난한 기본기 |
| 루비 | 300 | 시작할 때 보호막 1개 |
| 민트 | 700 | 콤보 지속 +50% |
| 섀도 | 1,300 | 조향 반응 +25% |
| 골드 | 2,200 | 코인 점수 +30% |
| 레인보우 | 3,500 | 아이템 지속 +40% |

- **코인 부활**: 한 판에 한 번, 코인 300개로 되살아남 (새 차 사기와 저울질하게 되는 값)
- **오늘의 도전**: 날짜 해시로 매일 규칙 하나를 골라 별도 기록으로 관리
  - 한 번의 기회(하트 1개, 점수 2배) / 전력 질주(처음부터 고속, 1.5배) / 코인 러시(코인 2배, 하트 없음) / 맨몸 주행(파워업 없음, 1.8배)
- 소리 켜기/끄기, 진동 켜기/끄기

### 시작 화면
- 장난감 블록이 쌓이는 제목 애니메이션, 뒤에서 도로가 계속 흐르는 어트랙트 모드
- 가운데 차를 누르면 빵빵 경적 반응

## 4. 화면 흐름 / 구조

```
시작 화면 ──▶ 카운트다운 ──▶ 주행 ◀──▶ 일시정지
  │  ├─ 기록 (TOP 5 · 도전과제 · 누적 통계)      │
  │  ├─ 차고 (차 구매/선택)                        ▼
  │  └─ 오늘의 도전 ─────────▶ 주행        게임오버 ──▶ 코인 부활 (1회)
  └──────────────────────────────────────── 재시작 / 메뉴
```

| 파일 | 역할 |
|---|---|
| `index.html` | 캔버스 + HUD + 오버레이 화면(시작/일시정지/기록/차고/게임오버) DOM |
| `style.css` | UI 스타일. 9:16 비율 고정 레이아웃 |
| `game.js` | 게임 루프, 물리, 충돌, 패턴 스폰, 점수/콤보, 추격전, 세이브, Web Audio 사운드 |
| `sprites.js` | Canvas2D 그림 전부(차, 장애물, 아이템, 사람/동물, 배경, 바이옴 팔레트) |
| `test_chase.js` | Node `vm`으로 `game.js`를 실제로 불러와 게임 로직과 밸런스를 검증 (DOM/캔버스/오디오는 가짜 객체로 대체) |
| `GRAPHICS_TASK.md` | 그래픽 담당 작업 공간(gfx 브랜치)에 준 작업 지시서 |

- 논리 해상도는 **360×640 고정**. 도로는 가운데 240px, 양옆은 잔디
- 고해상도 화면에서는 내부 픽셀만 `devicePixelRatio`(최대 2배)로 키우고 좌표계는 그대로 유지

## 5. 기술 스택

| 기술 | 선택 이유 |
|---|---|
| Vanilla JavaScript | 빌드 도구·프레임워크 없이 파일을 열기만 하면 실행됨 |
| HTML5 Canvas 2D | 60fps 스프라이트 렌더링. 이미지 파일 없이 도형 명령으로 직접 그림 |
| Web Audio API | 효과음과 BGM을 오실레이터로 실시간 합성해 외부 사운드 파일 0개 |
| localStorage | 서버 없이 기록·코인·차고·도전과제 저장 (`SAVE_VERSION` 포함) |
| Vibration API | 지원 기기에서 피격/획득 진동 피드백 |
| Node.js (`vm`) | 브라우저 없이 게임 로직을 돌려보는 테스트 |

## 9. 트러블슈팅 · 배운 점

**점수의 90%가 코인에서 나옴** (`82cabde`)
- 원인: 이미 60fps 기준으로 맞춘 `dt`를 거리 공식에서 16.6으로 한 번 더 나눠, 주행 가치가 초당 3.6점까지 떨어짐
- 해결: 중복 보정을 제거하고, 거리 점수에도 레벨·콤보 배수를 곱해 거리 비중을 13% → 29%로 올림

**물웅덩이가 함정이 아니라 속도 버프였음** (`6641c20`)
- 원인: 좌우 속도가 `v = acc * fric / (1 - fric)` 로 수렴하는데, 마찰을 0.80 → 0.93으로 올린 효과가 가속 하향보다 커서 밟으면 오히려 74% 빨라짐
- 해결: `SLIPPERY_ACC` 0.5 → 0.26. 되돌리면 실패하는 테스트 단언도 추가

**보행자를 예측할 수 없음** (`350bfcd`)
- 원인: 걷는 속도가 빨라 플레이어 앞에 오기까지 최대 3.5차선(212px)을 가로지름. 빈 곳을 보고 꺾으면 보행자가 그쪽으로 걸어옴
- 해결: 속도를 낮춰 최악 88px로 줄이고, 이를 확인하는 `worstCrosserDrift` 테스트 추가
- 속도를 25% 낮춘 뒤 드리프트가 다시 118px로 커져서 보행자 속도도 같은 비율로 낮춤 (`fa89d23`)

**도로를 가로지르는 검은 선** (`18d898e`)
- 원인: `drawWindmill`의 지붕 꼭짓점이 `lineTo(x, ...)`가 아니라 `lineTo(0, ...)`로 적혀 있었음
- 추적 방법: `CanvasRenderingContext2D.prototype.lineTo`를 잠깐 가로채서, 넓고 거의 수평인 선분이 그려지는 순간의 호출 스택을 잡음

**바나나를 밟은 뒤 회전이 홱 꺾임** (`9a0aa15`)
- 원인: 미끄럼이 끝나는 순간의 각도를 정면으로 되감았는데, 반 바퀴 근처에서 끝나면 크게 반대로 돎
- 해결: 되감지 않고 같은 방향으로 계속 돌아 다음 2π 배수에서 멈추게 함

**오일 연출이 차까지 가려 조작 불능** (`294e37a`)
- 원인: 반지름 150px 반투명 얼룩이 3초 동안 화면 가운데를 덮음
- 해결: 작고 불투명한 방울 5~8개를 차 위쪽(y ≤ 380)에만 뿌리고 하나씩 걷히게 함

**게이트 한가운데로 지나가면 판정이 안 됨** (`294e37a`)
- 원인: 두 문 사이에 16px 틈이 있었음
- 해결: `GATE_W`를 도로 폭의 정확히 절반(120)으로 맞춰 틈을 0px로 만듦

**144Hz 모니터에서 먼지가 2.4배 쏟아짐** (`294e37a`)
- 원인: 파티클 스폰 확률이 `dt`를 무시함
- 해결: `dt` 보정으로 비율을 2.4 → 1.02로 맞춤

**Alt+Tab 하고 돌아오면 차가 벽에 붙어 있음** (`294e37a`)
- 원인: 창이 포커스를 잃으면 `keyup`이 오지 않음
- 해결: `window blur`에서 입력을 비우고, 흩어져 있던 같은 코드를 `releaseAllInput`으로 합침

**안드로이드에서 기록/차고 화면 스크롤 불가** (`fddd6eb`)
- 원인: `e.scale`은 사파리 전용이라 다른 브라우저에서는 `undefined`가 되고, 모든 `touchmove`가 취소됨
- 해결: 실제 두 손가락 핀치일 때만 취소

**화면 비율 · 고해상도 문제** (`cbe5cee`, `2805381`)
- 3배 밀도 화면에서 흐림: 내부 픽셀만 `devicePixelRatio`에 맞추고 `setTransform`으로 좌표계는 유지
- 창에 맞춰 캔버스가 가로로 최대 23% 늘어남: `max-width`/`max-height`를 반대쪽 변에서 계산해 9:16 고정

**두 작업 공간 협업**
- 로직(main)과 그래픽(gfx)을 폴더·브랜치로 분리하고 `GRAPHICS_TASK.md`에 함수 이름, 충돌 박스, 외부 리소스 금지 규칙을 명시
- 그 결과 `sprites.js`가 `game.js`의 `draw`를 가로채 덧그리는 방식이 생겨 효과가 두 번 그려짐 → 호출 방식을 정식 함수 호출로 바꾸고 가로채기 코드는 제거 (`c3f78b9`)
- 테스트가 게임 코드를 실제로 불러오기 때문에, 그래픽 쪽에서 함수 이름을 잘못 바꾸면 바로 걸림

**밸런스는 측정해서 맞춤**
- 차 가격: 테스트용 전 차량 무료 플래그가 켜진 채였음. 실제 수입(판당 190~315코인)을 재서 전부 모으는 데 70판 넘게 걸리던 가격을 약 32판으로 낮춤
- 점수 도전과제: 첫 판에 자동으로 달성되던 기준을 150k/500k로 올리고, id에서 숫자를 빼 기준이 바뀌어도 기록이 어긋나지 않게 함
